# 一次性临时对话（2026-09-25）

以根目录 `PRODUCT_ARCHITECTURE.md` 为总规范。本次复用已经验证的页面内对话机制，在聊天历史总开关开启时提供一次性“不保存”入口。

## 产品行为

- Chat 左侧增加“临时对话”，与“开始新对话”并列。
- 临时对话支持“先听我说、帮我理一理、给我建议、陪我练”四种方式和连续多轮消息。
- 顶部和消息区持续显示：不保存历史、不进入长期记忆、刷新或离开后消失。
- 用户切换历史、开始另一段对话或重开临时对话时，如果已有临时消息，需要确认放弃。
- 结束临时对话只更新当前页面状态，不生成或伪造数据库摘要。
- 全局“保存聊天历史”关闭时，新对话继续沿用相同的不入库行为；此时无需额外显示临时入口。

## 数据边界

- 浏览器只在当前 React 页面状态中保存正文，不使用 localStorage、sessionStorage 或 IndexedDB。
- Server Action 仍接收每一轮消息以生成当前 mock 回复，但 repository 在 `saveHistory = false` 时不创建 `Conversation` 或 `ConversationMessage`。
- 临时对话不创建 `Memory`，未来记忆提取器也必须显式排除该来源。
- 当前没有调用真实 AI。接入模型服务商时，需要重新说明请求正文在第三方服务的处理和保留规则。

## 验收步骤

1. 保持 Settings 中“保存聊天历史”开启。
2. 打开 Chat，点击“临时对话”，确认顶部与正文区出现临时提示。
3. 连续发送两条消息并切换陪伴方式，确认当前页面能够继续对话。
4. 确认左侧历史没有增加新条目。
5. 刷新页面，确认临时内容消失，已有历史不受影响。
6. 再次进入临时对话并发送消息，点击一条历史；选择取消时留在临时对话，确认后才离开。
7. 运行 `npm run db:verify-chat-history-setting`，验证开启总开关时的临时请求仍不入库且不产生 Memory。
