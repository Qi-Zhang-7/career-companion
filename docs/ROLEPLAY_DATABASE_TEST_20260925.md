# Role Play 数据库闭环与验收

更新时间：2026-09-25

## 本轮已完成

- `/roleplay` 从数据库加载当前用户的人物、关系摘要、观察、沟通策略及最近 12 次练习。
- 创建练习时写入 `RoleplaySession`，并创建第一条角色消息。
- 用户每次回应与规则生成的角色回复均写入 `RoleplayMessage`，使用 `sequenceNo` 保持顺序。
- 结束练习后，针对用户是否说明依赖和时间节点生成具体复盘，保存到 `reviewJson`，会话状态改为 `ARCHIVED`。
- 最近练习支持重新打开：未结束会话可以继续，已结束会话可以回看复盘。
- 所有查询和写入均限定当前演示用户，所选人物也验证归属。

## 当前仍是 mock 的部分

- 对方回复由难度和轮次规则生成，没有调用模型。
- 复盘由关键词规则生成，不是 Reflection Agent 的模型输出。
- “进入完整复盘”目前只携带 `source` 与 `sessionId` 跳转，尚未创建正式 `Reflection` 记录。
- Prompt 模板已建立，但没有接入 Agent 运行时。

## 手工体验步骤

1. 打开 `/roleplay`，确认人物来自“职场关系”中的现有人物。
2. 选择人物、场景、目标、角色风格和难度，进入沟通准备。
3. 创建模拟并连续发送两次回应。
4. 刷新页面，确认模拟消息仍存在。
5. 点击“结束模拟并复盘”，确认展示具体做得好的地方、改进点、替代表达和下次重点。
6. 返回设置页，确认“最近练习”可打开刚才的练习。
