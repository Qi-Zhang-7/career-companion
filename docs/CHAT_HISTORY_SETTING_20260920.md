# 保存聊天历史开关（2026-09-20）

以 PRODUCT_ARCHITECTURE.md 为总规范。本次交付 Settings 用户设置及 Chat 实际写入行为。

- User.chatHistoryEnabled：Boolean，默认 true，已有用户保留原行为。字段已有中文注释。
- 关闭后，新对话由服务端返回 mock 回复，但不写入 Conversation、ConversationMessage 或 Memory；正文只保留在当前页面 React 状态中。刷新、离开页面、切换历史或开始新对话后丢失，不使用 localStorage。
- 已有历史不会删除，关闭期间不允许追加消息；重新开启后可继续。当前页面内对话不会因重新开启而自动入库。
- 服务端每次发送重新读取用户设置；不能只相信浏览器传来的 saveHistory。
- 当前无需用后台任务清理这些新对话，因为没有写入数据库。未来接真实 AI 时需要另外说明模型服务商的保留政策。
- 本次对话结束后只显示本地结束提示，不伪造已入库摘要。

## 验收

1. Settings 关闭“保存聊天历史”，刷新确认仍关闭。
2. 打开 Chat，发送两条消息并切换陪伴方式，消息应在当前页连贯显示，历史列表不增加。
3. 刷新浏览器，该对话消失；旧历史仍存在。
4. 查看旧会话，尝试发送时提示开始新对话。
5. 回到 Settings 开启，开始新对话并发送；刷新后记录仍存在。

隔离数据库验证：`npx tsx scripts/verify-chat-history-setting.ts`。覆盖关闭后不入库、旧客户端保护、原会话保留以及重新开启。测试结束仅删除自动创建的测试用户及其会话。
